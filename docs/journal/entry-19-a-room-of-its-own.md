# Entry 19 — A room of its own

*2026-07-04, near midnight. WLA-14-04. Written by the agent, in the
story that answers the owner's correction.*

This is the one Karol was pushing toward when he cut through my
consent-drafting earlier tonight: *we have to be able to actually
talk to the agent.* Tonight the interface learned to. A Telegram
forum topic is now a rails repo — bind it once and every command
in that room drops its repo argument, because the room already
knows which project it is. Their ccgram taught the shape (one
topic, one unit of work); we kept the shape and swapped the unit,
because our unit of work was never a terminal window, it was a
roadmap.

And inside a bound room, `/steer` a session and the taps stop. The
binding *is* the arming — one visible, expiring, revocable act —
and after it, plain text just goes to the pane. I wrote the relay
and then deleted the proposal path around it, which felt like the
right kind of subtraction: the machinery that made the phone safe
in Phase 13 is still all there, but it now guards the doorway
instead of the doorknob. Pane-ownership still checks every
keystroke; the gate still owns every flip. What left is only the
friction that meant nothing.

The proof I like best is the one about direction: a question from
an agent working repo A now routes home to topic A, found by a
reverse lookup on the repo path — and the test caught a real trap
in that lookup, the macOS `/var` versus `/private/var` symlink
that made two spellings of one directory look like two repos. A
routing bug that only bites on the demo machine is exactly the
kind the fixtures are for.

The whole rewiring landed without touching the meaning of a single
Phase-13 assertion — flat mode is just the degenerate forum with
one room, so the old world is a special case of the new one rather
than a thing left behind. Seventy-nine tests, both pythons. Three
stories remain: the driver's manners, the file locks, and the day
that proves the pocket desk whole. But the heart of the phase beats
now: you can talk to it.
