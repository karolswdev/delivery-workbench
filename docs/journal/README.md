# The Phase 12 journal

This is a working journal, kept while Phase 12 of this repository's
own roadmap is delivered on its own rails. Phase 12 integrates
Delivery Workbench with [HoldSpeak](https://github.com/karolswdev/HoldSpeak)
and proves the agent riders (Claude Code, Codex, pi), and every
story ships a journal entry in the same gated commit as the work it
describes.

Two audiences at once:

- Someone evaluating **Delivery Workbench** who wants to see what
  working on the rails actually feels like — commands, refusals,
  evidence, the lot — rather than read about it in the abstract.
- Someone writing a **HoldSpeak plugin pack** who wants a complete,
  honest example of one being built, tested, and shipped.

## The charter

Recorded by WLA-12-01; every entry from 0 onward is governed by it.

**Voice.** First person, present tense, written while the work
happens — not reconstructed afterward. Plain language: if a term
needs a glossary, the entry explains it in place. The writer is
whoever is doing the work, human or agent, and says so.

**Cadence.** One entry per story, shipped in the same gated commit
that flips the story done — the entry is part of the story's
deliverable, not a follow-up. Entry 0 covers the phase opening; a
short closing note may ride the phase-close commit. No entry is
ever written for work that didn't happen.

**Honesty bar.** Refusals, dead ends, failed evidence captures, and
verified negatives stay in — on these rails a refusal is usually
the system working. Corrections are appended, never rewritten; if
history embarrasses us, it stays embarrassing. Where an entry
predates a rule (entry 0 predates this charter), the rule wins and
the contradiction stays documented. Entries link to evidence and
story files rather than duplicating them, so the journal can be
read as narrative and audited as history.
