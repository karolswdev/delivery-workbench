# The Phase 12 journal

This is a working journal, kept while Phase 12 of this repository's
own roadmap is delivered on its own rails. Phase 12 integrates
Delivery Workbench with [HoldSpeak](https://github.com/karolswdev/HoldSpeak)
and proves the agent riders (Claude Code, Codex, pi), and every
story ships a journal entry in the same gated commit as the work it
describes.

Two audiences at once:

- Someone evaluating **Delivery Workbench** who wants to see what
  working on the rails actually feels like — commands, refusals,
  evidence, the lot — rather than read about it in the abstract.
- Someone writing a **HoldSpeak plugin pack** who wants a complete,
  honest example of one being built, tested, and shipped.

Ground rules (the full charter is a WLA-12-01 deliverable and will
be recorded here when that story lands): entries are first person
and present tense, written while the work happens, one per story.
Refusals, dead ends, and failed evidence captures stay in — on
these rails a refusal is usually the system working.
